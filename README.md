Sujal Portfolio

A responsive, animated personal portfolio website with galaxy and blackhole video backgrounds, scroll-triggered animations, and a working contact form.

🔗 Live Demo

https://sujalguptaportfolio1.netlify.app/

✨ Features
Galaxy and blackhole video backgrounds
Scroll-based animations (CSS scroll timeline + AOS)
Fully responsive, with a mobile sidebar menu
Projects section with hover-to-play video previews
Downloadable resume button
Contact form powered by Formspree
🛠️ Tech Stack
HTML5
CSS3
JavaScript (Vanilla)
AOS for animations
Boxicons for icons
Formspree for the contact form
Hosted on Netlify
📁 Project Structure
portfolio/
├── index.html
├── style.css
├── style.js
├── Sujal_Resume.pdf
├── images/
└── videos/
🚀 Run Locally
bash
git clone https://github.com/sujalgu75/portfolio.git
cd portfolio

Open index.html in your browser, or use the Live Server extension in VS Code.

Note: Videos and images are hosted with the live site. If they are missing from this repo, the local version will show without media.
